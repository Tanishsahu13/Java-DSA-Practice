## 📌 How this repo works

- Every morning I get a fresh set of **15 problems** — roughly *3 Easy · 11 Medium · 1 Hard* — chosen to skip what I've already solved and to hit my weak areas (strings, two pointers, trees, graphs, DP).
- Each day's set is logged in [`daily/`](daily/) with the problem list, difficulty, LeetCode link and the core pattern behind each problem.
- Solutions in Java are added as I work through them; the tracker in [`PROGRESS.md`](PROGRESS.md) keeps the running totals.
